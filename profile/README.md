# BMLA - Bicocca Machine Learning Association

`contact@bicoccamla.com` | [Website](https://bicoccamla.com/) | [LinkedIn](https://www.linkedin.com/company/bmla-bicocca) | [Instgram](https://www.instagram.com/bmla_bicocca) | 

BMLA is a student-led Machine Learning community at the University of Milano-Bicocca.  

We bring together students passionate about AI, Machine Learning and Data Science through collaborative projects, reading groups, technical events and talks with researchers and industry professionals.  

### 🏗️ GitHub repository structure

This organization contains the code and resources behind BMLA's activities and projects.
You may find repositories containing:

- workshop and event-related materials
- educational resources
- collaborative projects
- tools and infrastructure used by the association
- We aim to keep our projects open, reproducible, and accessible whenever possible.

🤝 We're open to collaborations involving:

- technical workshops  
- seminars and talks  
- research-oriented activities  
- student projects  
- partnerships and events

For questions, collaborations, or general information, feel free to get in touch with us.
